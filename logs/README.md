# RK3568 启动日志归档

平台：Rockchip RK3568 评估板，LPDDR4 2GB
日志时间范围：2026-03-05 ~ 2026-03-07

## 目录结构

### 0305-DDR训练/ （11个文件）
3月5日记录的 DDR 预加载器训练日志，涵盖 V1.13 版本。
- 部分文件为加载动画字符（`| / - \`），表明启动卡住
- 部分包含完整的 DDR 内存训练输出（TDQSS 值、频率爬升等）
- 030505.txt 还包含 healthd 电池监控日志

### 0306-UBoot启动与故障/ （5个文件）
3月6日的完整启动流程日志，包括：
- 030601.txt / 0601.txt：DDR V1.18 预加载器，系统成功启动后的 IO 域诊断脚本
- 030602.txt / 0602.txt：SoftReset 后的 DDR 重新训练
- Linux启动日志.txt：DDR v1.25（2025/12/03，最新版本）预加载器
- 0306.txt / 06-1.txt：含多次启动失败记录（DTB加载失败、内核哈希不匹配等）

### 0307-对比参考/ （2个文件）
已知正常板子的基准启动日志，用于与问题板对比：
- MobaXterm_COM8USB-SERIALCH340COM8_20260307_133433正常板子.txt：3月7日抓取的正常板 DDR V1.18 日志
- 正常启动日志.txt：DDR V1.16 版本正常启动参考

### 硬件替换调试/ （7个文件）
调试过程中更换不同组件后的日志对比：
- 只换了boot.txt：仅更换 boot 模块后的日志
- 换了uboot和boot之后.txt：同时更换 UBoot + boot 后的日志
- 更换MniniLoaderAll.txt：更换 MiniLoaderAll 预加载器后的日志
- 更新了两个模块日志也换了uboot.txt：多模块更新后的日志
- 坏板最新启动日志.txt / 错误日志启动不了.txt：问题板的故障日志
- 最新.txt：最近一次抓取，训练值与坏板接近，修改未解决问题

### error_logs/02_uboot_issues/
空目录，预留用于存放 UBoot 相关问题日志。

## 关键发现

| 固件版本 | 日期 | 备注 |
